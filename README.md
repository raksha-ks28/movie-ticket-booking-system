# movie-ticket-booking-system
A DBMS-based Movie Ticket Booking System
## Technologies used
-PHP
-MYSQL
-HTML
-XAMPP

## Features
-User Registration
-User Login
-Movie Listing
-Ticket Booking
-Booking Management 

## Project Description
This project is a database-driven Movie Ticket Booking System as a DBMS mini project. It allows users to register, log in, view available movies, and book tickets using a MYSQL Database
